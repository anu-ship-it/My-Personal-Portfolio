TokenPulse

Flagship
Manifest V3Vanilla JSChrome APIsMutationObserver

A browser extension that shows real token usage, context-window headroom, and rate limits across ChatGPT, Claude, Gemini, and DeepSeek. No external dependencies — content scripts parse each platform's DOM and, for Claude, read authenticated session data directly for real limits instead of estimates. Everything is stored locally: no account, no servers, no data leaving the browser.
